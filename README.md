Smile Dental Clinic – Website Redesign

This project is a redesign of a local dental clinic website created as part of the UI/UX Design Internship (Task 1). The objective was to design a clean, modern, and user-friendly website that focuses on improving trust and increasing appointment bookings.

The website was designed keeping real users in mind — mainly patients looking for reliable dental services and an easy way to book appointments. The layout is simple, structured, and conversion-focused.

The project includes three main pages:

Homepage

Services Page

Contact / Appointment Page

The homepage highlights the clinic’s value proposition clearly and includes strong call-to-action buttons to encourage bookings. The services page presents dental treatments in a structured card layout so users can quickly understand available options. The contact page includes a simplified appointment form along with clinic details to reduce friction and improve lead generation.

Design decisions were made to maintain clarity and trust. Soft blue tones were used to reflect hygiene and professionalism. Spacing and typography were kept consistent across pages to ensure visual balance and readability. The form fields were intentionally minimal to make appointment booking easier for users.

Tool used:

Figma (for UI design and layout)
